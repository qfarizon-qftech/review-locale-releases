# Revue locale

Revue locale est une application desktop qui ouvre une fenêtre pour relire et annoter les changements Git. Son skill permet de lancer les revues depuis Codex, Claude Code ou Cursor.

## Télécharger

- [Dernière version](https://github.com/qfarizon-qftech/review-locale-releases/releases/latest)
- [Signaler un bug ou proposer une amélioration](https://github.com/qfarizon-qftech/review-locale-releases/issues/new/choose)

Choisissez l’installeur correspondant à votre système :

- **Linux x64** : AppImage ; rendez le fichier exécutable avant de l’ouvrir.
- **Windows x64** : installeur Inno Setup.
- **macOS** : image disque pour Mac Intel ou Apple Silicon.

Git doit être installé et disponible dans le `PATH`. Node.js et Python ne sont pas nécessaires pour l’application distribuée.

Les mises à jour publiques sont disponibles sans compte GitHub. Sur macOS, l’application doit être signée avec un certificat Apple valide pour que les mises à jour fonctionnent correctement.

Pour créer une issue, connectez-vous à un compte GitHub. Les téléchargements et les mises à jour restent accessibles sans compte.

## Installer le skill

Au premier lancement, sélectionnez Codex, Claude Code et/ou Cursor. L’application installe le skill dans le dossier utilisateur de l’assistant choisi. Redémarrez ensuite l’assistant si nécessaire.
